# AI Recruitment Intelligence System Backend

FastAPI backend for AI-powered resume screening and candidate ranking.

Recruiters can paste a job description, upload multiple PDF/DOCX resumes, and receive the top matching candidates ranked by semantic similarity, skill overlap, and ML probability.

## Features

- PDF and DOCX resume upload
- Resume text extraction
- Text preprocessing
- SentenceTransformer embeddings with `all-MiniLM-L6-v2`
- Semantic similarity with cosine similarity
- Skill matching score from required skills
- Logistic Regression prediction with `model.pkl`
- Final ranking score:

```text
semantic_score * 0.4 + skill_match_score * 0.2 + ml_probability * 0.4
```


## Endpoints

### Health Check

```text
GET /api/health
```

### Screen Uploaded PDF/DOCX Resumes

```text
POST /api/screen/upload
```

Form fields:

- `job_description`: recruiter job description
- `top_n`: number of ranked candidates to return
- `required_skills`: optional comma-separated skills
- `files`: multiple PDF/DOCX resumes

### Screen Text Resumes

```text
POST /api/screen/text
```

Example JSON:

```json
{
  "job_description": "Looking for a Machine Learning Engineer with Python, Docker, AWS and Kubernetes.",
  "top_n": 10,
  "required_skills": ["python", "docker", "aws", "kubernetes"],
  "resumes": [
    {
      "candidate_name": "Candidate One",
      "category": "Machine Learning",
      "text": "Machine Learning Engineer with Python, AWS, Docker and Kubernetes experience."
    }
  ]
}
```

### Screen Existing Dataset

```text
POST /api/screen/dataset?job_description=...&top_n=10
```

This uses `models/processed_resumes.csv`.

### Generate Dataset Embeddings

```text
POST /api/embeddings/generate
```

This creates:

```text
models/resume_embeddings.npy
```

The backend reuses this file for dataset screening instead of regenerating resume embeddings every request.
